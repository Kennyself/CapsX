# CapsX 用户手册

**产品：** CapsX
**版本：** 1.1.0
**适用系统：** Windows 10 与 Windows 11（64 位）
**更新日期：** 2026-10-16

CapsX 把很少用到的 CapsLock 变成一个修饰键。按住它，再用主键区的字母，就能移动光标、选中文字和删除文字，双手不用离开键盘中心。

短按 CapsLock 仍然切换大小写。当前版本的快捷键是固定的，还不能在界面里改键。

## 1. 这是什么

CapsX 是一个驻留在任务栏通知区域的小程序，没有主窗口。它适合经常打字、写代码，又不想伸手去按方向键的人。

它做三件事：

- 短按 CapsLock，照常切换大小写。
- 按住 CapsLock 再按字母，执行光标和编辑操作。
- 从托盘图标启用、暂停或退出。

第一次运行会安装一个键盘驱动，之后这台电脑不用再装。驱动装完必须重启一次，重启前快捷键不会生效。

## 2. 第一次使用

按下面的顺序做一次即可。

- [ ] 双击完整编译的 `CapsX.exe`
- [ ] 在提示里选择安装键盘驱动，并同意管理员权限
- [ ] 安装完成后重启电脑
- [ ] 再次打开 `CapsX.exe`，确认任务栏出现图标

勾选只保存在这台电脑的浏览器里，用来给自己做记号。

### 2.1 安装键盘驱动

1. 双击 `CapsX.exe`。
2. 如果这台电脑还没装驱动，会看到提示：CapsX 需要先安装键盘驱动，装完必须重启一次。选择“是”。
3. 如果当前不是管理员，Windows 会弹出用户账户控制。选择“是”。
4. 安装过程中会出现“正在安装键盘驱动，请稍候…”。
5. 成功后会问是否现在重启。选择“是”，电脑大约 5 秒后重启。
6. 回到桌面后，再双击一次 `CapsX.exe`。

安装器已经打进 `CapsX.exe`，不需要另外下载，也不用自己打开命令行。

> **权限被拒绝**
>
> 如果在用户账户控制里选择“否”，程序会提示“没有获得管理员权限，CapsX 没有修改系统设置”，然后退出。系统不会被改动。下次想安装时，重新双击即可。

### 2.2 怎样算安装完成

任务栏通知区域出现圆形图标，鼠标停上去显示 `CapsX - Enabled`。从这一刻起，快捷键开始生效。

图标是蓝底白字 `CX`。暂停后变成灰底，提示变为 `CapsX - Disabled`。

## 3. 日常启动与退出

驱动装好之后，平时直接双击 `CapsX.exe`，不需要管理员权限。

- 左键单击托盘图标：在启用和暂停之间切换。
- 右键单击托盘图标，选择 `Exit`：退出程序。快捷键立即停止。
- 已经有一个 CapsX 在运行时，再打开会提示“CapsX 已在运行，无法启动第二个实例”。先用的那个不受影响。

当前版本没有开机自启开关。如果希望登录后自动运行，可以把 `CapsX.exe` 的快捷方式放进 Windows 启动文件夹。

## 4. 短按、长按与组合键

判断标准是按下的时长，以及中间有没有按过别的键。时间界限大约是 150 毫秒。

### 4.1 短按

按下后很快松开，中间不按其他键。大小写会切换一次，和原来的 CapsLock 一样。指示灯跟着系统状态变化。

### 4.2 长按后松开

按住超过大约 150 毫秒，中间没有按其他键，再松开。大小写不会切换，也没有别的动作。用这个方式可以避免误触。

### 4.3 按住再按其他键

按住 CapsLock 不放，再按字母。大小写不会切换。有对应功能的字母会执行功能；没有对应功能的键照常输入。

松开 CapsLock 后，键盘恢复普通输入。

暂停 CapsX 之后，CapsLock 回到系统原来的行为，上面三种区分都不再出现。

## 5. 快捷键

下面所有操作都是：先按住 CapsLock，再按字母。键位按标准 QWERTY 键盘设计。

```
Q    W 退格   E 上移   R 删除   T  Y  U   I 上选   O  P
 A 行首  S 左移  D 下移  F 右移  G 行尾  H 选首  J 左选  K 下选  L 右选  ; 选尾
```

按住字母不放时，对应动作会连续重复，和按住方向键一样。

### 5.1 移动光标

| 按键 | 作用 |
|------|------|
| CapsLock + E | 上移 |
| CapsLock + D | 下移 |
| CapsLock + S | 左移 |
| CapsLock + F | 右移 |
| CapsLock + A | 跳到行首 |
| CapsLock + G | 跳到行尾 |

这组键的手感接近把方向键挪到 `ESDF`。`A` 在这一排的最左边，表示行首；`G` 在最右边，表示行尾。

### 5.2 选中文字

| 按键 | 作用 |
|------|------|
| CapsLock + I | 向上选中 |
| CapsLock + K | 向下选中 |
| CapsLock + J | 向左选中 |
| CapsLock + L | 向右选中 |
| CapsLock + H | 选中到行首 |
| CapsLock + ; | 选中到行尾 |
| Shift + CapsLock + A | 选中到行首 |
| Shift + CapsLock + G | 选中到行尾 |

`I J K L`、`H` 和 `;` 自己会带上 Shift，不用再按 Shift。

移动键也可以用来选中：按住 Shift 和 CapsLock，再按 `E`、`D`、`S`、`F`、`A` 或 `G`，效果与按住 Shift 再按方向键、Home 或 End 相同。

### 5.3 删除文字

| 按键 | 作用 |
|------|------|
| CapsLock + W | 删除光标左边的字符，相当于退格 |
| CapsLock + R | 删除光标右边的字符，相当于 Delete |

先选中一段文字，再按 `W` 或 `R`，会删掉选中的内容。

### 5.4 没有绑定的键

按住 CapsLock 时，`Q`、`T`、`Y`、`U`、`O`、`P`、数字以及其他没有出现在上表里的键，仍然输入原来的字符。Ctrl、Alt、Shift 和 Win 也会照常传给系统。

已经被占用的字母不会再交给当前程序。例如按住 CapsLock 时按 `S`，得到的是向左移动，不是字母 S，也不会触发原来的 Ctrl+S。

## 6. 托盘菜单

右键单击图标，菜单如下。

| 菜单 | 作用 |
|------|------|
| Enable | 启用 CapsX。启用时这一项前面有勾。 |
| Disable | 暂停 CapsX。暂停后 CapsLock 恢复系统原样。 |
| Settings | 打开后提示设置界面尚未提供。当前不能改键，也不能调节 150 毫秒的时间界限。 |
| About CapsX | 查看版本号和项目地址。 |
| Exit | 退出程序。 |

左键单击图标，等价于在 Enable 和 Disable 之间切换。

项目地址：[https://github.com/kennyself/CapsX](https://github.com/kennyself/CapsX)

## 7. 遇到问题

按现象对照。做完一项就重新打开 `CapsX.exe` 试一次。

### 7.1 提示必须先重启

驱动已经装上，但这次开机还没加载它。选择“是”立即重启，或自己重启后再运行。

### 7.2 重启后仍然连不上驱动

程序会指出安全启动还开着，或给出检查顺序：

1. 确认已经重启过。
2. 重启进主板设置，关闭 Secure Boot 并保存。安全启动不能由 CapsX 代为关闭。
3. 打开 Windows 安全中心，进入“设备安全性”，再进入“内核隔离”，关闭“内存完整性”，然后重启。
4. 右键 `CapsX.exe`，选择“以管理员身份运行”。

### 7.3 安装失败或图标没有出现

- 确认使用的是完整编译的 `CapsX.exe`。不完整的程序会提示找不到内置安装器。
- 安装时选择允许管理员权限。
- 自动重启失败时，手动重启后再运行。
- 查看日志：`%APPDATA%\CapsX\capx.log`。在资源管理器地址栏粘贴 `%APPDATA%\CapsX` 可以打开这个文件夹。

### 7.4 快捷键没有反应

- 看托盘提示是不是 `CapsX - Enabled`。如果是 `Disabled`，左键点一次图标。
- 确认按住的是 CapsLock，并且字母是上表里的键。
- 确认驱动安装之后已经重启过。

## 8. 常见问题

### 8.1 长按会不会把大小写切乱

不会。只有短按、并且中间没有按过其他键，才会切换一次大小写。按住 CapsLock 做快捷键时，指示灯保持原样。

### 8.2 能不能改键或改时间

当前不能。`Settings` 会说明设置界面尚未提供。快捷键和时间界限（约 150 毫秒）都是固定的。

### 8.3 暂停之后原来的 CapsLock 还在吗

在。暂停或退出之后，CapsLock 就是系统原来的大小写键。

### 8.4 程序会不会记下我输入的内容

不会。按键只在内存里用来判断要不要换成快捷键，不写入文件，也不上传。日志里只有启动、停止和按键动作的技术记录，没有你输入的正文。
