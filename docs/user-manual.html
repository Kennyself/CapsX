CapsX · v1.1.1

按住 CapsLock，
光标就在主键区

短按仍切换大小写。按住再按字母，移动、选中和删除都不用离开键盘中心。

CapsX 驻在任务栏通知区域，没有主窗口。它适合经常打字、又不想伸手去按方向键的人。快捷键目前是固定的，还不能在界面里改。

系统
Windows 10 与 Windows 11，64 位
时间界限
短按小于 150 毫秒
日期
2026-10-16

01

三种按法

松手之前，有没有按过别的键。

短按

< 150 ms

很快松开，中间不按其他键。大小写切换一次，指示灯跟着系统走。

长按

≥ 150 ms

按住达到 150 毫秒再松开，中间没有别的键。大小写不会切换，也没有别的动作。

组合

按住 + 字母

按住不放再按字母。大小写不动。有绑定的键执行功能，其余照常输入。

暂停之后，这三种区分都消失，CapsLock 回到系统原来的大小写键。

02

键位

先按住 CapsLock，再点一个字母。

下面两排按实体键盘的位置画：上一排是 Q 到 P，下面是 A 到 L，并且整排向右错开。灰色键没有绑定。点一个键，右边写出它实际做的事。

  • 移动
  • 选中
  • 删除

CapsLock + E

上移

光标向上一行。按住不放会连续移动。

再按住 Shift，改为向上选中。

I、J、K、L、H 和分号自己会带上 Shift。H 选中到行首，分号选中到行尾。移动键要选中时，也可以按住 Shift 和 CapsLock，再按 E、D、S、F、A 或 G。

灰色键、数字，以及 Ctrl、Alt、Shift、Win，按住 CapsLock 时仍照常交给系统。已经被占用的字母不会再输入原来的字符：按住 CapsLock 时按 S，得到的是向左，不是字母 S，也不会触发 Ctrl+S。

04

第一次使用

装一次驱动，然后重启。

安装器已经在 CapsX.exe 里。这台电脑只做一次，不用自己打开命令行。驱动装完之前，快捷键不会生效。

双击程序，同意安装

如果还没装驱动，会问是否现在安装。选择“是”。提示写明：装完必须重启一次，之后不用再执行命令。

权限被拒绝

在用户账户控制里选择“否”，程序会说“没有获得管理员权限，CapsX 没有修改系统设置”，然后退出。系统不会被改动。想装的时候重新双击即可。

05

托盘

图标在任务栏里。

启用时是蓝底白字 CX，提示 CapsX - Enabled。暂停后变成灰底，提示 CapsX - Disabled。左键单击，在启用和暂停之间切换。右键打开下面这个菜单。

菜单

Enable

启用 CapsX。启用时这一项前面有勾。左键单击图标也是同一件事。

已经有一个 CapsX 在运行时，再打开会提示“CapsX 已在运行，无法启动第二个实例”。先用的那个不受影响。菜单里的 Launch at startup 有勾时，登录 Windows 会自动打开当前这个程序。再点一次就取消。

06

排错

连不上，或键没有反应。

做完一项就重新打开 CapsX.exe 试一次。

提示必须先重启

驱动已经装上，但这次开机还没加载它。选择“是”立即重启，或自己重启后再运行。

重启后仍然连不上驱动
  1. 确认已经重启过。
  2. 进主板设置，关闭 Secure Boot 并保存。安全启动不能由 CapsX 代为关闭。
  3. 打开 Windows 安全中心 → 设备安全性 → 内核隔离，关闭“内存完整性”，然后重启。
  4. 右键 CapsX.exe，选择“以管理员身份运行”。
安装失败，或图标没有出现
  • 确认用的是完整编译的程序。不完整时会提示找不到内置安装器。
  • 安装时允许管理员权限。
  • 自动重启失败时，手动重启后再运行。
  • 日志在 %APPDATA%\CapsX\capx.log。把 %APPDATA%\CapsX 贴进资源管理器地址栏即可打开。
快捷键没有反应
  • 托盘提示应是 CapsX - Enabled。若是 Disabled，左键点一次图标。
  • 确认按住的是 CapsLock，并且字母在上表里。
  • 确认驱动安装之后已经重启过。
它会记下我输入的字吗

不会。按键只在内存里用来判断要不要换成快捷键，不写入文件，也不上传。日志里只有启动、停止和按键动作，没有正文。
