CapsX
手册 需求 设计

Design · v0.2.0

技术设计

对应需求 v1.1.1。没有设置窗口。托盘菜单是 Enable、Disable、Launch at startup、About、Exit。长按时间固定为 150 毫秒。选中到行首、行尾是 CapsLock + H 和 CapsLock + ;。

这是设计草案的阅读版。完整代码片段和早期方案仍在 technical-design.md。当前程序的选中绑定以下面的 SEL-05、SEL-06 为准。

01

架构

CapsX 编成一个 exe。单实例锁、按键处理、绑定表和托盘都在这个进程里。分发时复制这一个文件；第一次运行会从 exe 里释放键盘驱动安装器。

按键不走低级钩子回调。Interception 在内核过滤驱动里拿到扫描码，用户态线程把它映射成虚拟键，再交给状态机决定拦截、放行或注入。

02

按键与绑定

三种状态

空闲、按下中、组合中。CapsLock 按下时先拦截，操作系统还没收到这个键，指示灯不会闪。150 毫秒内松开且没有别的键，就注入一次 CapsLock 切换。否则不注入。

默认绑定

查找是一张短表上的线性扫描。选中类绑定的 withShift 为真，注入时会先按下 Shift，再按下目标键，然后按相反顺序松开。

触发注入选中
E / D / S / F方向键否
A / GHome / End否。按住 Shift 时，因为 Shift 被放行，效果变成选中。
W / RBackspace / Delete否
I / K / J / LShift + 方向键是
HShift + Home是，选中到行首
;（VK_OEM_1）Shift + End是，选中到行尾

分号键的扫描码是 0x27。钩子用 MapVirtualKey 得到 VK_OEM_1，绑定表用这个虚拟键，而不是字符本身。

H       → VK_HOME, withShift
VK_OEM_1 → VK_END,  withShift

03

托盘

没有主窗口。消息窗口收托盘回调。左键切换启用，右键菜单是 Enable、Disable、Launch at startup、About、Exit。About 显示 v1.1.1。Launch at startup 写在当前用户的 Run 项里。长按时间固定为 150 毫秒。

启用时图标是蓝底白字 CX，暂停时是灰底。

04

配置

当前没有 JSON 配置。绑定写在 binding_manager.cpp。日志在 %APPDATA%\CapsX\capx.log。设计草案里的 settings.json 仍是后续方案，里面的选中项应包含 H 与分号：

"home": { "key": "H", "target": "Home", "withShift": true },
"end":  { "key": ";", "target": "End",  "withShift": true }

05

构建

CMake 工程版本是 1.1.1，语言标准 C++17。Interception 源码静态链进 exe，并定义 INTERCEPTION_STATIC。官方安装器作为 RCDATA 打进程序，构建前文件必须存在。

MSVC 使用 /utf-8。MinGW 使用 Unicode 入口和静态运行库，资源代码页 65001。

06

已知限制

  • 驱动安装后必须重启。安全启动或内存完整性打开时，驱动可能加载失败，程序不能代为关闭。
  • 同一台机器只能有一个 CapsX。驱动不支持多个客户端同时拦截。
  • 自定义绑定还没有。长按时间固定为 150 毫秒，没有设置窗口。
  • 设计草案前半部分仍有早期低级钩子方案的叙述。实现以 Interception 路径为准。
